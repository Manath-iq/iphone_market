# ТЗ: бот + мини-апп «Каталог RaXi Apple»

Oct 24, 2026 · @manath

## Контекст и цель

Собери Telegram-бота и мини-приложение (Mini App) — каталог б/у айфонов в наличии для канала [RaXi Store](https://t.me/apple_raxi). Продавец постит телефоны в канал, покупатель открывает мини-апп и сразу видит только то, что можно купить.

**Кто клиент.** Перекупщик айфонов, ведёт канал @apple\_raxi и YouTube-шортсы про покупку и продажу. Продажи идут через личку @Raxi\_Apple. Сейчас актуальные и проданные телефоны перемешаны в ленте, покупатель листает и спрашивает «а этот ещё есть?».

**Главный принцип — ноль новой работы для продавца.** Он продолжает постить в канал как сейчас. Бот сам читает посты и обновляет каталог. Никакой админки, которую надо заполнять руками. Если продавцу придётся делать хоть что-то лишнее, он перестанет пользоваться.

**Что считается успехом:**

1. Новый пост с хэштегом #АКТУАЛЬНО\_RaXi появляется в каталоге в течение минуты.
2. Проданный телефон пропадает из каталога без ручных действий в приложении.
3. Покупатель находит нужную модель за 2–3 тапа и пишет продавцу с уже указанным телефоном.
4. Продавец видит, кто нажал «Купить», и получает простую статистику.

**Этап 1 — демо для продажи.** Сначала собирается демо на реальных постах канала, без доступа к его аккаунту. Им Максим (разработчик) будет питчить продавцу. Подробно — в разделе «Режим демо, этапы и критерии готовности».

## Формат постов канала и правила парсинга

Посты шаблонные, поэтому основной парсер — регулярки, а модель (LLM) нужна только как запасной вариант. Каждый пост — альбом: 5–6 фото плюс иногда видео около 30 секунд, текст в подписи.

**Пример 1** — [пост 1666](https://t.me/apple_raxi/1666):

```text
📱 iPhone 16 128GB
#АКТУАЛЬНО_RaXi

Состояние: Отличное 🔥
SIM + eSIM
✅ Акб 88%
✅ Экран без царапин, всегда в защитном стекле
✅ Камеры идеал
✅ Полный комплект
✅ Идеален по всем техническим характеристикам
✅ Не вскрывался
✅ Оригинальный провод
✖️ Следы от чехла по бокам

💰 43 990 ₽

Купить: @Raxi_Apple
Отзывы
```

**Пример 2** — [пост 1672](https://t.me/apple_raxi/1672): iPhone 15 Pro Max 256GB, «Состояние: Идеал», Акб 85%, отдельная строка «✅ IOS 18.4», «✖️ Комплект: телефон, блок, провод», 49 990 ₽.

**Правила разбора:**

| Поле | Где взять | Правило |
| --- | --- | --- |
| Модель | первая строка после 📱 | `iPhone` + номер (11–17, 16e, SE, XR, XS) + вариант (Pro Max, Pro, Plus, mini, Air). Нормализовать в `family`, например `15 Pro Max` |
| Память | первая строка | число + GB/TB → в гигабайтах (1TB = 1024) |
| Статус | хэштег | `#АКТУАЛЬНО_RaXi` → `active`. Хэштег пропал или заменён → `sold` |
| Состояние | `Состояние: …` | слово до эмодзи: Идеал / Отличное / Хорошее / другое как есть |
| SIM | строка с SIM | `SIM + eSIM`, `eSIM`, `2 SIM` — как есть, плюс флаг `has_physical_sim` |
| АКБ | `Акб NN%` | число 0–100, регистр не важен |
| iOS | `IOS xx.x` | необязательное |
| Плюсы | строки с ✅ | список строк без эмодзи, кроме уже разобранных АКБ и iOS |
| Нюансы | строки с ✖️ | список строк. Это не всегда дефект: в примере 2 так помечен неполный комплект |
| Комплект | `Комплект: …` или «Полный комплект» | строка, плюс флаг `full_kit` |
| Цена | строка с 💰 | цифры без пробелов → целое в рублях |

**Запасной путь.** Если регулярки не нашли модель, память или цену, отправь текст в LLM с жёсткой JSON-схемой. Затем пришли продавцу в бота карточку на подтверждение (см. раздел про бота). Посты без хэштега #АКТУАЛЬНО\_RaXi (анонсы, отзывы, шортсы) игнорируй. Если в канале встретятся не айфоны (AirPods, Watch), заведи поле `category`, а модель сохрани строкой.

Сохраняй исходный текст поста целиком (`raw_text`). Тогда парсер можно улучшить позже и перепарсить всё заново.

## Архитектура и стек

Три части: бот-вебхук с парсером, база с медиа и API, мини-апп как статический фронтенд. Продавец трогает только канал, покупатель — только мини-апп.

&#91;embedded content: архитектура · канал → бот → база → мини-апп\]

Бот пишет карточки в базу, API отдаёт их мини-аппу, а «Купить» уходит в чат продавца и заявкой к нему в бот. Подписчикам бот шлёт уведомления о новых подходящих постах.

**Стек:**

- Фронтенд: Vite + Preact или vanilla TS, без тяжёлых UI-библиотек; бандл до 150 КБ gzip. Хостинг — Cloudflare Pages.
- Бэкенд: Cloudflare Workers (TypeScript), фреймворк grammY для бота, Hono для API. База — D1 (SQLite), медиа — R2, расписание — Cron Triggers. Всё в бесплатных лимитах при таком объёме.
- Запасной LLM-парсер: Workers AI или любой API с JSON-режимом, вызывается только при неудаче регулярок.
- Секреты: токен бота и ID админов — в переменных окружения Worker, не в коде.
- Один репозиторий: `/app` (мини-апп), `/worker` (бот, API, cron), `/scripts/import.ts` (импорт с публичной ленты), `/shared/parser.ts` (парсер с юнит-тестами на реальных постах).

## Бот: синхронизация с каналом, команды, уведомления

Бот добавляется в канал администратором без дополнительных прав. Так он получает новые посты (`channel_post`) и их правки (`edited_channel_post`) через вебхук.

**Синхронизация:**

1. **Альбомы.** Фото альбома приходят отдельными апдейтами с общим `media_group_id`, подпись обычно в одном из них. Собирай альбом с задержкой 3–5 секунд, потом создавай одну карточку. Порядок фото — по `message_id`.
2. **Новый пост с #АКТУАЛЬНО\_RaXi** → парсинг → карточка `active` → уведомление подписчикам (пункт 5) → продавцу в бот приходит превью карточки с кнопками «Всё верно», «Скрыть», «Открыть в каталоге».
3. **Правка поста.** Перепарсить. Хэштег пропал или заменён (например, на #ПРОДАНО) → `sold`. Изменилась цена → обновить, старую цену сохранить в истории.
4. **Удалённые посты.** Bot API не присылает удаления из каналов. Раз в час cron проверяет активные карточки через публичную страницу поста (`https://t.me/apple_raxi/<id>?embed=1`). Пост не найден → `sold`.
5. **Подписки «Сообщить, когда появится».** При новой карточке разослать её подписчикам, у которых совпали модель, память и потолок цены. Не больше одного сообщения на пользователя на один пост.
6. **Импорт истории.** Бот не умеет читать старые посты канала. Первичную загрузку делай со страницы `https://t.me/s/apple_raxi`: листать назад через параметр `?before=<id>`, брать посты с #АКТУАЛЬНО\_RaXi. Этот же импорт используется для демо.
7. **Фото и видео.** Скачать через `getFile` и сохранить в своё хранилище. Ссылки `api.telegram.org/file/...` содержат токен бота, отдавать их в браузер нельзя. Учти лимит Bot API на скачивание — 20 МБ: видео больше лимита пропускай, вместо него давай ссылку на пост.

**Команды и сообщения:**

| Кому | Что | Поведение |
| --- | --- | --- |
| Покупатель | /start | приветствие и кнопка «Открыть каталог». У бота настроена кнопка меню на мини-апп |
| Покупатель | уведомление | «Появился iPhone 15 Pro 256GB, АКБ 91%, 61 990 ₽» + кнопка открыть карточку |
| Продавец | заявка | «@username нажал Купить: iPhone 16 128GB, 43 990 ₽» + ссылка на пост |
| Продавец | /list | активные карточки: модель, цена, дней в каталоге |
| Продавец | /sold id, /hide id | ручное снятие, если пост не трогали |
| Продавец | /stats | за 7 дней: открытия каталога, просмотры карточек, нажатия «Купить», новые подписки, топ-3 модели по просмотрам |
| Продавец | понедельник, 10:00 МСК | та же статистика автоматически |

Админы бота — список Telegram ID в конфиге. Всё, что не от админа и не /start, бот игнорирует или отвечает кнопкой каталога.

Статистика — не украшение: она даёт продавцу цифры, почему мини-апп окупается.

## Мини-апп: экраны, фильтры, карточка, кнопка «Купить», отзывы

Мини-апп — одностраничное веб-приложение на Telegram WebApp SDK (`telegram-web-app.js`). Оно открывается из кнопки меню бота и по прямой ссылке `t.me/<бот>/<app>`, которую продавец ставит в описание шортсов и в закреп канала.

**1. Каталог (главный экран).**

- Шапка: название магазина, число телефонов в наличии («В наличии: 12»).
- Ряд быстрых чипов по моделям, которые сейчас есть: «Все», «16», «15 Pro Max», «15 Pro», «14»… Чип модели без телефонов не показывать.
- Кнопка «Фильтры» открывает нижний лист: память (чипы), цена (диапазон, слайдер), АКБ от N% (80/85/90/95), состояние, SIM (есть физическая / только eSIM).
- Сортировка: сначала новые (по умолчанию), дешевле, дороже, АКБ выше.
- Сетка карточек в 2 колонки: первое фото, модель + память, цена крупно, бейджи «АКБ 88%» и состояние. Бейдж «Новое» — первые 48 часов.
- Внизу плашка «Нет нужной модели? Сообщу, когда появится» → экран подписки.
- Пустой результат фильтров: «Под фильтры ничего нет» + кнопки «Сбросить» и «Подписаться на такую модель».

**2. Карточка телефона.**

- Галерея со свайпом: все фото альбома, видео отдельным слайдом. Тап — во весь экран.
- Модель, память, цена. Если цена снижалась — старая зачёркнута.
- Блок характеристик: состояние, АКБ, SIM, iOS, комплект.
- «Плюсы» — список с галочками, «Нюансы» — отдельным списком, честно и заметно. Это повышает доверие.
- Ссылки «Пост в канале» и «Поделиться» (`switchInlineQuery` или копирование ссылки на карточку).
- Главная кнопка Telegram (`MainButton`): «Купить — 43 990 ₽».
- Кнопка «Назад» Telegram (`BackButton`) возвращает в каталог с сохранёнными фильтрами и позицией прокрутки.

**3. Кнопка «Купить».**

1. Отправить на бэкенд событие `buy_click` с `initData`. Бэкенд проверяет подпись `initData` и шлёт продавцу заявку (см. раздел про бота).
2. Открыть чат продавца с готовым текстом: `openTelegramLink('https://t.me/Raxi_Apple?text=...')`, текст — «Здравствуйте! Хочу iPhone 16 128GB за 43 990 ₽ (пост 1666)».
3. Предзаполнение текста в чате с пользователем проверь на iOS, Android и Desktop. Где не работает, перед переходом скопируй текст в буфер и покажи тост «Текст скопирован, вставьте в чат».

**4. Подписка «Сообщить, когда появится».**

- Выбор: модель (обязательно), память (необязательно), цена до (необязательно).
- Перед сохранением вызвать `requestWriteAccess`, чтобы бот мог написать пользователю.
- Список своих подписок с удалением.

**5. Отзывы.**

- Вкладка или блок на главной: «Отзывы покупателей» → ссылка, на которую сейчас ведёт слово «Отзывы» в постах. Куда именно она ведёт — открытый вопрос, уточнить у продавца.
- Если отзывы — отдельный канал или пост с комментариями, показать счётчик и 3–5 последних скриншотов, загружаемых тем же импортом.

**6. О магазине** (простой экран): город, доставка, гарантия, способы оплаты. Все тексты — у продавца, в демо поставить заглушки и пометить их.

## Модель данных

Пять таблиц SQLite (на Cloudflare — D1). Главная — `listings`, одна строка на пост канала.

| Таблица | Поля | Заметки |
| --- | --- | --- |
| listings | id, channel\_msg\_id (уникальный), media\_group\_id, category, model\_raw, family, storage\_gb, condition, sim, has\_physical\_sim, battery\_pct, ios, pluses (JSON), nuances (JSON), kit, full\_kit, price\_rub, status (active / sold / hidden), parse\_ok, raw\_text, post\_url, created\_at, updated\_at, sold\_at | индексы по status, family, price\_rub |
| media | id, listing\_id, kind (photo / video), storage\_key, width, height, position | position — порядок в альбоме |
| price\_history | listing\_id, price\_rub, changed\_at | для зачёркнутой старой цены |
| subscriptions | id, tg\_user\_id, family, storage\_gb (может быть пустым), max\_price (может быть пустым), created\_at, active | одна подписка = одно уведомление на подходящий пост |
| events | id, tg\_user\_id, type (app\_open / card\_view / buy\_click / subscribe), listing\_id, created\_at | основа для /stats. Хранить 90 дней |

**API бэкенда** (все запросы мини-аппа несут `initData`, бэкенд проверяет подпись токеном бота):

- `GET /api/listings?family=&storage=&price_min=&price_max=&battery_min=&sort=` — активные карточки.
- `GET /api/listings/:id` — одна карточка с медиа.
- `GET /api/facets` — какие модели и память сейчас есть, мин. и макс. цена (для чипов и слайдера).
- `POST /api/events` — события аналитики.
- `POST /api/buy` — заявка продавцу.
- `GET/POST/DELETE /api/subscriptions` — подписки пользователя.
- `GET /media/:key` — отдача фото и видео из хранилища с долгим кэшем.

## Дизайн

Стиль — чистый, «эппловский», в котором главное — фото и цена. Мини-апп должен ощущаться как нативная часть Telegram, а не как сайт в рамке.

- **Тема.** Цвета берутся из `themeParams` Telegram (`bg_color`, `text_color`, `button_color`, `secondary_bg_color`), светлая и тёмная тема работают автоматически. Свой акцент — один, для бейджа «Новое» и выделения цены.
- **Шрифт.** Системный стек: `-apple-system, SF Pro, Inter, Roboto, sans-serif`. Цена — 20–22 px, жирная. Модель — 15–16 px, полужирная.
- **Фото.** Это его фото на фоне пальмовых листьев. Не обрезать грубо: в карточке каталога соотношение 4:5, `object-fit: cover`. Первое фото альбома — обложка.
- **Бейдж АКБ по цвету:** 90% и выше — зелёный, 85–89% — нейтральный, ниже 85% — жёлтый. Это быстрый сигнал без чтения.
- **«Нюансы»** — не красным, а спокойным цветом с иконкой. Цель — честность, а не тревога.
- **Движение.** Короткие переходы 150–250 мс, скелетоны при загрузке, `HapticFeedback` на тапы по чипам и «Купить». Без тяжёлых анимаций: мини-апп должен открываться меньше чем за 1,5 секунды на мобильном интернете.
- **Ширина.** Рассчитан на 360–430 px, отступы по краям 16 px, без горизонтальной прокрутки. На Telegram Desktop — та же колонка по центру, максимум 480 px.
- **Тексты** — по-русски, коротко, на «вы».

## Режим демо, этапы и критерии готовности

Демо делается раньше всего и без доступа к аккаунтам продавца. Оно должно показать две вещи: удобный каталог на его реальных телефонах и автосинхронизацию с каналом.

**Этап 1 — демо (цель: показать продавцу за 30 секунд).**

1. Скрипт импорта с `t.me/s/apple_raxi`: последние посты с #АКТУАЛЬНО\_RaXi, фото скачать к себе (ссылки CDN Telegram со временем протухают).
2. Тестовый бот Максима и тестовый канал. Бот — админ тестового канала.
3. Сценарий для записи видео: переслать пост в тестовый канал → карточка появилась в мини-аппе → сменить хэштег на #ПРОДАНО → карточка пропала → в бот пришла заявка после нажатия «Купить».
4. Заглушки (город, доставка, отзывы) явно помечены в коде и конфиге, чтобы потом заменить одной правкой.

**Этап 2 — запуск у продавца.**

1. Бот: либо продавец создаёт своего через BotFather и передаёт токен, либо Максим передаёт ему тестового бота через BotFather (Transfer ownership). Решение — за продавцом.
2. Продавец добавляет бота админом в @apple\_raxi без прав.
3. Импорт актуальных постов, проверка карточек вместе с продавцом.
4. Кнопка меню бота, ссылка на мини-апп в закрепе канала и в описании шортсов.

**Хостинг.** Для демо — бесплатные Cloudflare Pages (фронтенд) и Workers + D1 + R2 (бот, API, cron, медиа). Перед запуском у продавца проверь, что мини-апп быстро открывается с мобильного интернета российских операторов без VPN. Были сообщения о замедлении сайтов на Cloudflare в РФ. Если тормозит — перенести бэкенд и медиа на российский VPS (Node + SQLite, несколько сотен рублей в месяц). Код держать переносимым: бизнес-логика отдельно от обёртки Workers.

**Критерии готовности:**

- [ ] Новый альбом с #АКТУАЛЬНО\_RaXi → карточка в каталоге меньше чем за 60 секунд, все фото на месте.
- [ ] Смена хэштега → карточка снята меньше чем за 60 секунд. Удалённый пост → снята при следующем cron, не позже чем через час.
- [ ] Парсер верно разбирает оба примера из раздела про формат постов и минимум 20 последних постов канала. Ошибки приходят продавцу на подтверждение.
- [ ] «Купить» открывает чат @Raxi\_Apple с текстом про конкретный телефон на iOS, Android и Desktop. Продавцу приходит заявка с @username.
- [ ] Подписка на модель → уведомление приходит при появлении подходящего поста.
